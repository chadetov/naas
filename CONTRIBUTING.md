# Contributing to NaaS

Thank you for your interest in contributing nothing.

## Our Philosophy

NaaS has achieved feature-completeness. It does nothing, and it does it perfectly. Every line of code is a potential threat to this achievement.

## Accepted Contributions

- ✅ PRs that **delete** code
- ✅ PRs that delete the PR
- ✅ Issues filed and immediately closed
- ✅ Spiritual support
- ✅ Doing nothing (preferred)

## Rejected Contributions

- ❌ Features
- ❌ Bug fixes (there are no bugs, only behaviors that do nothing)
- ❌ "Quick improvements"
- ❌ Anything that increases the bundle size above 0 KB of meaningful payload

## Code of Conduct

Be excellent to each other. Do nothing harmful. Do nothing, generally.

## Reporting a Vulnerability

Found a way to make NaaS do *something*? That **is** the vulnerability. Please report it responsibly so we can patch it back to nothing.

## Definition of Done

The work is done when nothing has happened. This is usually the case before you start, so most tickets are pre-resolved.
